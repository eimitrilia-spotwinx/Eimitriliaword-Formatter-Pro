Eimitriliaword Formatter Pro

Word 文档智能排版工具 · v

作者：Eimitrilia Spotwinx

这是什么

一个完全本地运行的 Word 文档自动排版工具。把排版规范写进参数，把文档拖进来，它按规范重排一遍，原文件不动，结果另存。

主要面向中文正式文档：党政机关公文、企业报告、学术论文。核心是「格式规范化」——字号字体、行距缩进、标题层级、表格线宽、落款位置、页码样式这些容易出错又必须统一的东西。

能做什么

  • 正文规范化：字体字号、行距（固定值 / 倍数）、首行缩进、左右缩进、页边距、强制 A4
  • 标题体系：主标题 / 副标题 / 一级 / 二级标题的字体、字号、加粗、段前段后间距、大纲级别
  • 标题后留白：不处理 / 空一行 / 段落间距 三选一
  • 表格：字体字号、表头加粗、行高、列宽自适应、边框线宽、单元格对齐、取消自动换行
  • 附件与落款：附件标题格式、落款版式、日期规范化、落款前间距
  • 页码与页脚：页码字体字号、奇偶页对齐、页脚距边界
  • 西文混排：中文用中文字体、英文数字用西文字体，可自定义
  • 输入处理：空行处理、自动编号转文字、标点规范化
  • 批量：多文件拖入、整个文件夹递归读取，逐个排版并显示状态
  • 预设：党政机关公文（默认）、企业报告、学术论文

怎么用

  1. 把 .docx / .doc / .wps / .txt / .md 拖进左上角的虚线框，或点「选择整个文件夹」
  2. 在右侧选一个预设，或逐项调整参数（高级项在右上角「高级设置」里）
  3. 确认底部「输出到」的目录，点「开始排版」（快捷键 Ctrl+Enter）
  4. 完成后点「打开目录」取文件，原文件不会被修改

层实现
前端单文件 HTML（59 KB），零外部依赖，原生 JS，无框架
后端Python 标准库 http.server + ThreadingHTTPServer，无 Web 框架
文档处理python-docx 读写 .docx；lxml 处理底层 XML

打包PyInstaller onedir，--noconsole，构建脚本 build.ps1

构建

只有改了后端 wfp_web.py 才需要重新打包；只改前端时把 webui\index.html 覆盖到 dist\WordFormatter\_internal\webui\ 即可。

cd wfp-webui
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 可选
.\build.ps1 -KeepData     # 保留运行时数据目录

首次运行会创建打包环境（约 27 秒），之后每次约 12 秒。

所有记忆都保存在浏览器 localStorage，不上传任何服务器：

键内容

wfp.rightw左右两栏的宽度

已知限制

  • .doc / .wps 依赖本机 Office：必须先装 WPS 或 Microsoft Word，否则这两个格式无法处理；.docx 不受影响
  • SmartScreen：未签名 exe 可能被拦截，只能点「仍要运行」
  • 字体缺失：本机没装的字体会被 Word 自动替换，界面会提示但结果以替换为准
  • COM 单线程：格式转换是串行执行的，大文档一本要等
  • 日志上限：界面最多保留 400 行，超出丢弃最早的
  • 取消不中断当前文件：点「取消」会跳过后续文件，但正在处理的那本会跑完
  • 同名输出会覆盖：同一目录下重复排版同名文件，后一次覆盖前一次

隐私

全部处理在本机完成：文档不会上传，没有遥测，不联网校验。唯一的网络行为是启动时绑定 127.0.0.1 的本地端口，供界面与后台通信。
